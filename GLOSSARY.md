# D2R Mobile: AYN Thor dual screen

Terms for running the Android port on two-screen handhelds (first target: the AYN Thor), where the game plays on one screen and our own companion UI uses the other.

## Language

**Top screen**:
The display the game itself renders to; on the Thor, the 6" 1920 × 1080 panel.
_Avoid_: main screen, primary display

**Bottom screen**:
The Thor's second, physical 3.92" display, shown as 1240 × 1080 in landscape.
_Avoid_: second screen, secondary display, lower screen

**Deck**:
Our companion UI shown on the bottom screen: live character readouts and large buttons for controller play.
_Avoid_: companion panel, second-screen panel, dashboard

**Panel**:
One of the game's own in-game windows (inventory, character, skill tree, quest log, stash, belt, game menu).
_Avoid_: using "panel" for the Deck or for the bottom screen

**Custom page**:
The page this port adds to the game's options, holding our own on/off switches; its rows are drawn by the game from the import pack.
_Avoid_: settings screen, preferences

**Build**:
A target plan for one character class on the Deck's Build tab: skill points, stats, gear, mercenary and breakpoints, in our own words, following a community guide (linked from it). One per class for now; each character's choice is remembered.
_Avoid_: guide (that is the linked web page), template, loadout

**Stage**:
One level band of a Build (for example "Act 1 Normal", up to level 13). A stage marked as a respec starts the skill plan over.
_Avoid_: phase, step

**Now column**:
The fixed left column of the Build tab: the character's next skill points, the next stat rule and a respec card when one is due, worked out from the character's own hard points.
_Avoid_: next steps panel, summary
